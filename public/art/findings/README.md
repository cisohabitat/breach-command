# Finding illustrations

Original artwork generated for Breach Command on 17 October 2026 following the
user-approved visual polish. Twelve distinct ink-and-paper miniatures match
the desk's bone and charcoal palette. No third-party artwork or brand marks.

The master is a four-column, three-row sheet retained outside the public
bundle. Each delivery WebP is 192 × 128, drawn at 96 × 64 on desktop and
72 × 48 on phones. The complete set is approximately 65 KB; a report requests
only the illustration it needs.

Rows, left to right: identity, network, email, DNS; firewall, server, cloud,
forensic; hunt, intelligence, maintenance, telemetry. The existing
`evidenceArtFor` public source/sector mapping selects these files, including
the OT maintenance exception and generic telemetry fallback. Hidden routes,
confidence, roll values and recommended actions never select artwork.

Images are decorative, keep an empty alt, reserve their frame on failure and
accompany the full written finding. These miniatures replace the older evidence
still lifes; no game surface requests the retired set.
