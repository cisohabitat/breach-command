# Signal and confidence

Signal measures whether a completed finding directly establishes an attack
stage. Confidence measures support for interpreting that finding in a causal
explanation. A confirmed stage remains an established fact, including when its
broader interpretation has weak confidence. Neither label assesses the whole
incident or grants permission to wait regardless of business pressure.

The first implementation derives both axes from the visible operation record:

| Finding | Signal | Confidence |
| --- | --- | --- |
| Rapid or balanced collection establishes a stage | Strong | Weak |
| Exhaustive collection establishes a stage | Strong | Strong |
| Rapid or balanced collection finds no new stage | Weak | Weak |
| Exhaustive collection finds no new stage | Weak | Strong |

A correct causal comparison between different collection sources strengthens
both findings' confidence. In new operations, each confirmed finding exposes
an action-record ID and its initiating record. One finding must explicitly
name the other's record as its initiator; stage adjacency, a shared route,
location and collection timing cannot establish this direct link. Records can
branch, skip stages or have an external initiator. These are authored fictional
incident facts, deterministic without consuming gameplay random draws.

A “Link not established” assessment, an incorrect assessment,
or two findings from the same source cannot do so. A wrong player assessment
does not change the underlying evidence. Exhaustive collection is confidence
within that source's coverage; it is not independent corroboration. Partner
findings and older records without collection metadata retain recorded confidence.

A failed roll produces no finding and settles neither axis. Roll magnitude,
the hidden chain and the hidden objective never set these labels. Correctly
assessing a new independent causal link grants the existing comparison relief
only when at least one finding has not already earned corroboration relief.
No-link, same-source and already-rewarded comparisons grant no meter or roll
reward. A capped reward still consumes its novelty; a wrong assessment retains
the impact and adversary penalties. Store actual clamped deltas and display
those figures, including zero changes. Response tradeoffs remain unchanged.
There is no score for certainty, and the review retains the evidence available to judge
decisions rather than rewarding a lucky guess.

The action sheet explains collection effects before commitment. Findings,
command decisions and the evidence reconstruction show the same assessment.
Training includes a four-combination guide in every Training scenario and at
the first decision. New operations carry comparison version 2 in session 21
and use BC11 challenges. Older operations retain their original comparison
rules and recorded wording; migration never fabricates provenance. Signal and
confidence still derive from the public collection and comparison history.

After a player makes a comparison that actually strengthens confidence, the
affected findings receive a brief border highlight and a persistent text notice names
the supporting sources, the weak-to-strong change and the unchanged signal.
Reduced motion disables the border animation. Loading or revisiting a saved
comparison does not replay the effect. With voice enabled, the Captain explains
the connection using the existing recorded voice, captions and Listen/Skip
controls. Automatic narration follows the existing once-per-cue-per-operation
policy; the player can replay it. A comparison that changes no confidence
does not trigger this feedback.

The linked-evidence view draws only recorded comparisons, plus an explicitly
untested preview of the selected pair. A valid causal relationship is labelled
supported even when the player incorrectly called it unestablished. An invalid
causal assertion is disputed; a correctly unestablished link says “Link not
established,” which does not prove the activities unrelated. Older operations
retain their original labels. Those labels describe the relationship, with the comparison
explanation below. Collection order never implies causal direction. A previously
tested pair cannot be submitted again. The view derives entirely from public
findings and comparison records; it never reads the hidden chain or objective.

Each source assessment carries a portrait and textual source-review attribution.
Prefer the on-call specialist when the procedure is in their expertise; otherwise
use the first specialist whose published expertise covers it, falling back to the
on-call specialist for partner or sector-specific records. This is desk-review
attribution, not a claim that a different specialist collected the finding or
supplied a game bonus. The original portraits are decorative and text remains
complete if they fail. Captain narration remains reserved for command updates.
